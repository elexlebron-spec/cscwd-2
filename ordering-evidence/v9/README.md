# Ordering-evidence dependence of collaboration rankings

Reproducibility artifact v9 for **How Much Ordering Evidence Supports a
Collaboration Ranking?**, by Zhiran Wang, Ocean University of China (2026).

The central observation is that certified score gaps do not order resistance
to losing case-order constraints. In the same 999-case permit log, lower margin
36 reverses after four case withdrawals (0.40%), while margin 16 requires
fourteen (1.40%). An independent-domain IT control keeps all 45 important
priorities after complete counter withdrawal. Finite positive examples remain
municipal and conditional on code scenarios, not business-confirmed sequences.

Start with [REPRODUCE.md](REPRODUCE.md):

```sh
python3 reproducibility/check_v9.py --manifest
python3 -m unittest discover -s tests -v
```

These commands need Python 3.9+ and no raw data. The guide distinguishes this
aggregate check from full raw-record reconstruction, frozen-cohort checks,
exact optimization and independent complete witness replay. All source
locations, hashes and expected results are given; no access to a private study
workspace is needed for the documented core path.

Contents: original numerical code, four test modules, fixed protocols,
complete query tables, comparison CSVs, aggregate cumulative-loss curves,
independent verification summaries and source/rights notices. There are 135
reference queries; the two municipal N/F analyses plus IT C give 225 model rows.

No raw logs, real case IDs, complete event tables/permutations, personal chat
review records, compiler/font caches or local machine paths are included.
Do not commit locally reconstructed raw/bounds/witness outputs back to this
artifact. GitHub history is not a dataset licence: read [DATA_NOTICES.md](DATA_NOTICES.md).

true-order reconstruction, employee-performance assessment or stakeholder trial.
